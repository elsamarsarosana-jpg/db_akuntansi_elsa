PROJECT CRUD LARAVEL - ELSA MARSA ROSANA

Cara menjalankan:
1. composer create-project laravel/laravel pro-akuntansi
2. Copy semua file ini ke project Laravel
3. Buat database: pro_akuntansi
4. Setting file .env
5. Jalankan:
   php artisan migrate
   php artisan serve

Buka:
http://127.0.0.1:8000/perkiraan
